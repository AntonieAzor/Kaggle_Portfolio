📊 E-Commerce Sales Analysis — SQL & Data Visualisation Project
📌 Overview

This project analyses an e-commerce dataset to understand the key factors driving revenue and profitability.

The goal was to identify:

What drives revenue
Which areas underperform
Where the business can improve

This project combines SQL analysis with data visualisation to simulate a real-world data analyst workflow.

🎯 Key Question

What factors have the biggest impact on revenue, and where should the business focus to improve performance?

🛠 Tools & Technologies
SQL (BigQuery / Kaggle) — data querying and aggregation
Tableau / Looker Studio / Google Sheets — data visualisation
GitHub — project documentation and asset hosting
📁 Dataset
Sample Superstore Dataset (Kaggle)
Contains transactional sales data including:
Orders, regions, and customer segments
Product categories and sub-categories
Sales, profit, quantity, and discount
🔧 Data Preparation
Checked for missing values
Standardised date formats
Created time-based fields (Year, Month)
Calculated additional metrics:
Profit margin = Profit / Sales
📊 Analysis (SQL)

Key areas explored:

🔹 Revenue Trends
Total revenue over time
Monthly and yearly performance
🔹 Product Performance
Revenue by category and sub-category
Profit comparison across categories
🔹 Customer Segments
Revenue by segment (Consumer, Corporate, Home Office)
Average order value
🔹 Geographic Analysis
Revenue by region and state
Top-performing locations
🔹 Profitability Analysis
Comparison of revenue vs profit
Identification of low-profit / negative-profit areas
🔹 Discount Impact
Relationship between discount levels and profitability
📈 Visualisation

A dashboard was created to present key findings, including:

Revenue trends over time
Revenue by category
Profit vs sales comparison
Top-performing regions

Visuals were designed to clearly communicate insights rather than maximise complexity.

🧠 Key Insights
Certain product categories generate high revenue but low profit, indicating inefficiencies
Heavy discounting is associated with reduced profitability
Revenue is concentrated in specific regions, suggesting opportunities for expansion
Customer segments differ in value, with some driving higher average order values
📢 Recommendations
Reduce discounting in low-margin categories
Focus on high-performing regions and expand similar markets
Prioritise products with strong profit margins, not just high sales
Target high-value customer segments for growth
🧾 Conclusion

This project demonstrates the full data analysis workflow:

Extracting and analysing data using SQL
Translating findings into visual insights
Communicating results in a clear, business-focused way

It highlights the importance of combining technical analysis with strategic thinking to support data-driven decision-making.
